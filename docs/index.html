Algoritmos

Este bot usa el algoritmo de Avellaneda-Stoikov de 2018
el micro-price para calcular el precio justo
y un algoritmo propio para calcular la aversión al riesgo
A continuación la lista de algoritmos que usa

  1. Micro-price
  2. Avellaneda-Stoikov 2018
  3. PZH Limit of Risk Aversion (se explica a profundidad más adelante)

Micro-Price

El micro-precio es el algoritmo para estimar el mejor precio en compra y venta para los quotes de las ordenes.
Las variables del algoritmo son las siguientes
  1. Imbalance discretizado en n buckets está denominado como I
  2. Spread bid-ask discretizado en m valores en ticks está denominado como S
  3. Numéros de estados del imbalance denominado como n
  4. Numéros de estados del spread denominado como m
  5. Vector de posibles cambios del mid-price denominado como K

Imbalance

Qb -> Volumen total en el mejor bid (bid size)
Qa -> Volumen total en el mejor ask (ask size)
Fórmula
I = Qb / (Qb + Qa)

Spread

Pa -> Mejor precio de venta (ask price)
Pb -> Mejor precio de compra (bid price)
Fórmula
S = Pa - Pb

Avellaneda-Stoikov

El algoritmo de avellaneda-stoikov es un algoritmo de market making
desarrollado por Sasha Stoikov y Marco Marcelo Avellaneda.
Swiss Exchange Market Maker (SXMM) usa la versión de 2018 de este algoritmo.
